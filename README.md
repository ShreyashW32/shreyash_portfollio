# Shreyash Wetal · Portfolio

My personal portfolio site: experience, research, projects and publications in
AI and computer vision.

**Live:** https://shreyashw32.github.io/shreyash_portfollio/

## Highlights

- An interactive terminal-style console for exploring my résumé.
- Engineer, recruiter and researcher views.
- A built-in assistant that answers questions about my work. It runs fully in the browser, so nothing you type is sent anywhere.
- A strict Content Security Policy, frame-busting and `security.txt`.

## Run locally

```bash
python -m http.server 8000
# open http://localhost:8000
```

## Tech

HTML, CSS and vanilla JavaScript, with no framework or build step. Hosted on GitHub Pages.
